# Capacitaciones NeTH3D

Página de las capacitaciones en robótica con Arduino y fabricación digital de NeTH3D.

- `index.html`: la página completa. Es un solo archivo, con las imágenes y los estilos adentro.
- Se publica con GitHub Pages desde la rama `main`.

Para editar textos o precios, se cambia directamente `index.html` y se vuelve a subir.
